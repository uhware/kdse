# KDSE-16 Catalog

The complete **KDSE-16** study space — binary container class `KDSE[2,15;16,2]`: minimal-form payloads of length 1, 3, 5, …, 15 (valid lengths are always odd), right-aligned in a 16-bit word with bit 15 unassigned and ignored.

Enumerated with the v1.0 reference library over payloads with bit 15 clear:

| Quantity | Count |
|----------|------:|
| Valid minimal-form payloads | 4,397 |
| Ordered forms (lowest-numerical sibling canonicalization) | 198 |
| Distinct terminal-depth profiles C(K) | 114 |

Under the equal-split threshold operator, profile-equivalent Ordered values share the same Raw Scalar response. **IJM events** = number of occupied depths in C(K).

Conventions: `bits` is the natural-width payload; `C(K)` counts terminals at each depth including implicit final terminals; Kraft identity `Σ c_d / 2^d = 1` holds for every row.

## Operator reminder

For uniform branch retention a = 1 − ℓ and threshold T (q = 2):

- activation location n_d = T (q/a)^d
- instantaneous jump J_d = T c_d
- gain increment Δg_d = c_d (a/q)^d

Branch loss shifts locations and slopes; jump magnitudes stay tied to multiplicity.
