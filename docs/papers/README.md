# KDSE papers

This directory contains the two companion papers that define KDSE and the instantaneous-jump-magnitude operator:

- `KDSE_Introductory_Paper.pdf` — structural definition, attributes, Ordered form, and operator separation.
- `KDSE_Deterministic_Instantaneous_Jump_Magnitude.pdf` — threshold-and-branch-loss response and the IJM derivation \(J_d = T\,c_d\).
