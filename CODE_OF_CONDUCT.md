# Code of conduct

**Repository status:** Read-only (v1.0). The expectations below apply whenever the project is open for participation.

Project participation requires technical candor, patience, and respect.
Discuss ideas and evidence directly; do not attack, harass, threaten, or
demean participants. Maintainers may edit or remove abusive material and may
restrict participation when necessary to protect constructive collaboration.

Report conduct concerns privately to the repository maintainers. Reports will
be reviewed as promptly and discreetly as practical.
